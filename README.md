# Веб-приложение для автоматического выявления западин на спутниковых снимках

Веб-приложение для автоматического выявления западин, потенциально связанных с процессами водородной дегазации, на основе спутниковых изображений и методов глубокого обучения.

## Описание проекта

Проект представляет собой систему, позволяющую:

* выделять интересующие области на спутниковой карте;
* автоматически загружать спутниковые тайлы;
* выполнять поиск западин с помощью модели YOLO;
* отображать результаты на интерактивной карте;
* сохранять результаты в базе данных;
* экспортировать найденные объекты в GIS-совместимые форматы.

Разработка выполнялась в рамках магистерской диссертации.

---

# Основные возможности

## Автоматическая детекция западин

* выбор произвольной области на карте;
* загрузка спутниковых изображений;
* запуск модели компьютерного зрения;
* отображение найденных объектов.

## Работа с результатами

* отображение найденных объектов поверх карты;
* удаление ложных срабатываний;
* хранение результатов в базе данных.

## Экспорт результатов в формте KML

Поддерживается экспорт:

* всей базы детекций;
* детекций внутри выделенной области.

# Принцип работы

1. Пользователь выделяет область на карте

2. Backend получает координаты области

3. Выполняется загрузка спутниковых тайлов

4. YOLO выполняет поиск западин

5. Координаты предсказаний преобразуются в географические координаты

6. Результаты сохраняются в PostGIS

7. Найденные объекты отображаются на карте
